# Pre-Post Checklist

Copy into the video's [[Video Log]] note and tick everything before posting.

## Script
- [ ] Opens with "You met me at a very ___ time in my life."
- [ ] Closes with "Gideon. This is not financial advice."
- [ ] Zero contractions
- [ ] One true, non-obvious fact, verified
- [ ] Gideon is not the butt of the joke
- [ ] No named real person, no employer reference, no protected group

## Video
- [ ] Every shot: same location, same light, same time of day
- [ ] Gideon inside the railing in every shot
- [ ] No garbage text rendered in-frame
- [ ] Earbud right ear, glasses module right temple, watch left wrist
- [ ] Generated audio muted; original ElevenLabs track laid over
- [ ] On-screen text (ticker / NFA) added in post, spelled correctly

## Caption
- [ ] Lowercase, no emojis, ≤6 hashtags
- [ ] `#gideon #onelayerdeeper` + 1 trend tag + 1 topic tag + `#fyp`
- [ ] "not financial advice" in caption if a real ticker is named
- [ ] Never explains the joke

## Platform
- [ ] TikTok AI-generated content label ON
- [ ] Same post mirrored to Instagram
- [ ] If paid / gifted / affiliate: branded-content toggle ON + "#ad" / "paid partnership" in caption + spoken or on-screen disclosure (see [[Guardrails & Compliance]])

## After
- [ ] Video Log note created with caption, tags and link
- [ ] Metrics at 24h / 72h / 7d
