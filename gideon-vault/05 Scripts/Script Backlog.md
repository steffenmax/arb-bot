## Pipeline for a backlog item

1. Rewrite the draft in the script note using [[Script Format]].
2. Fill `insight` (the one true fact) and get it verified ([[Fact Checker]]).
3. Change the note's `status` to `ready`.
4. Voice it, log split points in the note, move it to `05 Scripts/Produced`.

## Raw ideas

New hooks and blanks go in `11 Ideas` using [[Idea Template]]. Promote to a script note when a full escalation exists.
