# Caption Format

Modeled on the short-deadpan-line-plus-tags style. Written by the [[Caption Writer]].

## Template

```
"<one deadpan quote from the video, lowercase>"
#gideon #onelayerdeeper #<trend tag> #<topic tag> #fyp
```

## Example

```
"the qubits will stabilize"
#gideon #onelayerdeeper #youmetmeataverychinesetimeinmylife #quantum #fyp
```

## Rules

- **Always** `#gideon #onelayerdeeper` (own brand tags) + 1 trend tag + 1 topic tag + `#fyp`.
- Lowercase. No emojis. Never explain the joke. ≤6 hashtags.
- Toggle TikTok's **AI-generated content** label on every post.
- Include "not financial advice" in the caption when a real ticker is named.
- Paid / gifted / affiliate → "#ad" or "paid partnership" + branded-content toggle. See [[Guardrails & Compliance]].

## Tag bank

| Type | Tags |
|---|---|
| Brand (always) | `#gideon` `#onelayerdeeper` |
| Trend (rotate) | the current "you met me at a very ___ time" tag variant |
| Topic | `#quantum` `#ai` `#semiconductors` `#datacenter` `#investing` `#copper` `#energy` |
| Reach | `#fyp` |

> [!warning] Never use another creator's tags. `#childrenofkhan` and `#azerbaijantechnology` are off limits. See [[Inspiration - Luca Maxim]].
