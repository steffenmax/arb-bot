# Guardrails & Compliance

> [!danger] Must-follow for all agents and all humans. The [[Compliance Checker]] hard-blocks violations.

## Brand safety

- Gideon is fictional. **Never depict or voice real, identifiable people.** Never use real fund names as his employer.
- Never use Luca Maxim's characters, voice (a cloned "luca maxim" voice exists on Fish Audio — never use it), tags (`#childrenofkhan`, `#azerbaijantechnology`), or assets. See [[Inspiration - Luca Maxim]].
- Condescension punches at "the crowd," "amateurs," and consensus — **never at protected groups or named private individuals.**
- Keep the creator's day job completely separate: no references to the creator's employer, clients, or any non-public information.
- Creator should confirm their employer's outside-activity / social-media policy before monetizing, especially for anything touching specific securities. See [[Open Decisions]].

## Financial content

- Every video ends with "Gideon. This is not financial advice."
- Prefer themes over tickers. When a real ticker is named (e.g. QTUM), include NFA in the caption, and the creator should disclose if they personally hold it.
- Gideon's in-character "conviction" must never be used to make specific price predictions or guarantees.

## Paid promotions (critical once monetizing, especially crypto)

- Any paid, gifted, or affiliate promotion must be clearly disclosed (FTC): TikTok's branded-content toggle **and** "#ad" / "paid partnership" in the caption, and ideally spoken or on-screen.
- Promoting securities — which can include many crypto tokens — for compensation without disclosing the payment can violate SEC anti-touting rules (Securities Act Section 17(b)). Celebrities have been fined for this. **Never promote a token for pay without explicit compensation disclosure.**
- **Get legal review before the first paid crypto deal.**
- Do not accept deals for projects that cannot pass basic diligence. One rug-pull promo can kill the character's credibility, which is the entire asset.
- Gideon's conviction must never be used to make specific price predictions or guarantees for a paid sponsor.

## Sponsor diligence checklist (minimum)

- [ ] Named, verifiable team
- [ ] Product exists and can be used today
- [ ] No pending regulatory action found in a basic search
- [ ] Token, if any: no undisclosed insider allocation red flags
- [ ] Compensation terms in writing
- [ ] Disclosure language agreed in writing before production

## Hard blocks (the Compliance Checker fails the asset)

| Check | Block if |
|---|---|
| Real person | Any named real individual is depicted, voiced, or mocked |
| Employer | Any reference to the creator's employer, clients or non-public info |
| Protected group | Condescension aimed at a protected class |
| Undisclosed promo | Paid/gifted/affiliate without toggle + caption disclosure |
| Price promise | Any specific price target or guarantee |
| Copied IP | Another creator's character, voice, tags or assets |
| Missing NFA | Video does not end on the NFA close |
