# Gideon vault

An [Obsidian](https://obsidian.md) vault for the Gideon project: an AI-generated, single-character satirical finance account.

**Open it:** Obsidian → *Open folder as vault* → select this `gideon-vault` folder. Start at `00 Home/Gideon HQ.md`.

The vault ships with core-plugin config only (no community plugins required). Templates live in `Templates/` and are wired to the core Templates plugin. Attachments save to `02 Visual/assets/`.

`Source/` holds the original handover document verbatim. It is the source of truth; working notes summarize and link it.
